Automation

Price Tracker

Python · Playwright · Cron · Slack API

Independent Python scripts run daily on cron to watch nonstop flight searches and tracked tour listings, a Mac Mini, and an external drive. A shared module persists state and sends Slack alerts only when prices change, alerts on scraper failures, and skips scheduled work on Shabbat and Yom Tov; the Google Flights target uses Playwright because no public API exists.

Demonstrates: Resilient unattended automation: scraping a source with no public API, failure alerting instead of silent breakage, and calendar-aware scheduling shared across personal automation projects.

Zmanim & Torah-Learning Nudges

Python · Hebcal API · Cron · Slack API

A deterministic, dependency-free Python script posts daily halachic zmanim and Jewish-calendar context from Hebcal to Slack, including Friday candle-lighting and Havdalah details, and skips full Yom Tov. A companion nightly digest tracks a personal Torah-learning schedule; both run on cron tuned to the local timezone.

Demonstrates: Engineering judgment about where an LLM belongs: AI-assisted development helped build and iterate the tool, while the shipped scheduled artifact stays LLM-free because deterministic work is more reliable that way.
